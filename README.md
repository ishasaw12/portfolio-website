# Personal Portfolio Website

## Project Overview

This project is a personal portfolio website created using HTML5 and CSS. The website presents personal information, skills, and contact details in a structured format.

## Objectives

* Learn HTML5 webpage structure
* Use semantic HTML tags
* Create multiple sections in a webpage
* Build a simple portfolio layout

## Project Structure

* **index.html** – Main webpage file
* **images/** – Contains profile image
* **README.md** – Project documentation

## Website Sections

The website contains three main sections:

### About

Introduces the user and basic background information.

### Skills

Lists technical and programming skills.

### Contact

Contains a contact form with name, email, and message fields.

## HTML Concepts Used

* HTML5 document structure
* Semantic tags (header, nav, main, section, footer)
* Lists (ul, li)
* Image tag (img)
* Forms (input, textarea, button)
* Anchor links for navigation

## Technologies Used

* HTML5
* CSS
